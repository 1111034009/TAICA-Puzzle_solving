# 懸疑推理社 MYSTERY FILES

單檔懸疑推理視覺小說。你是推理社社長「霧島 澪」，要在有限的行動點內調查現場、比對證詞、排列時間線，並在天亮前指認真兇。

**單一 `index.html`，開啟就能玩。** 不需要安裝、不需要伺服器、不需要網路。

> 🔗 線上遊玩：`https://1111034009.github.io/TAICA-Puzzle_solving/`

---

## 特色

- **兩宗完整案件**：全部開放，可任意順序遊玩
- **主動調查**：點擊場景物件找線索，不只是按「下一步」
- **證據比對**：選兩項證物或證詞，找出矛盾、支持或補充關係
- **時間線重建**：自行排列事件順序，系統會說明哪裡前後衝突
- **質問與出示證據**：用證物或證詞反駁嫌疑人，讓對方鬆口
- **最終指認**：選擇犯人、動機、方法與關鍵證據，並確認時間線
- **四種結局與結案分析**：真相、證據鏈、時間線與漏掉的線索
- **100 分制評分**：推理、證據完整度、時間線、調查效率，等級 S～D
- **行動點與限時事件**：事件以調查行動推進，不懲罰閱讀速度
- **三階段提示**：需要累積調查進度才會解鎖，不扣分
- **原創 SVG 美術**：13 名角色、9 種表情、雨雪天氣與停電效果，全部內嵌在 HTML 內
- **合成音效**：WebAudio 即時生成，不含音檔，可隨時關閉
- **建議手機或平板遊玩**

## 案件

| 案件 | 類型 | 難度 | 場景 |
|---|---|---|---|
| **霧鴉館 ‧ 暴風雨之夜** | 暴風雨夜的密室事件 | ★★★☆☆ | 書房、廚房、大廳 |
| **雪華亭 ‧ 雪夜足跡** | 雪夜溫泉旅館的足跡事件 | ★★★★☆ | 離れ書房、雪之中庭、主屋玄關 |

- 霧鴉館：落地門閂、冰塊，與一場時間差。
- 雪華亭：雪停之前，有人走過了中庭。

每案各有 5 名嫌疑人、15 件證物與十多則證詞。每位嫌疑人都有秘密，但有秘密不代表是兇手。

## 操作方式

| 操作 | 說明 |
|---|---|
| 點擊場景物件 | 調查（首次取得證物消耗 1 點行動點，重看免費） |
| 底部按鈕 | 證據、人物、時間線、案件紀錄、提示、指認犯人 |
| 空白鍵／Enter／→ | 下一句 |
| `A` | 自動播放 |
| `L` | 對話回顧 |
| `M` | 音效開關 |
| `Esc` | 關閉面板或視窗 |

不需要 `npm install`，也不需要任何建置指令。


## 技術說明

- 單一 `index.html`（約 240 KB），HTML、CSS、JavaScript 全部內嵌，使用原生 JavaScript，無任何外部函式庫。
- 所有人物、場景、證物圖示與天氣效果皆為 JavaScript 產生的內嵌 SVG。
- 執行時不發出任何網路請求，不使用 localStorage、sessionStorage、IndexedDB 或 Cookie。
- 程式在同一檔案內分區：案件資料（`CASES`）、遊戲狀態（`GAME_STATE`）、評分（`SCORING`）、行動（`ACTIONS`）、美術（`ART`）、音效（`SND`）、畫面（`RENDER`）。
- 新增案件時，依現有案件的資料結構新增一份資料並加入 `CASES` 即可。

## 注意事項

- **不提供存檔**：重新整理或關閉頁面後，進度會消失。
- 音效需要在第一次點擊後才會播放（瀏覽器規定），可用右上角「音效」按鈕關閉。
- 字型使用系統字型，不同裝置上的外觀會略有差異。
